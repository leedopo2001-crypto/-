# 각색 스타일 가이드 — 각색팀(content-writer) 필독

## 버전 A — 렉카체 (숏폼 나레이션용, 45~60초)

이슈 유튜버 나레이션 톤. 구조는 고정:

1. **훅 (첫 3초)**: 결론의 냄새만 풍기고 시작. 의문형/도치.
   - "아니 이게 진짜 커뮤니티를 반으로 갈라버렸습니다."
   - "댓글 900개가 달렸는데요, 이유가 진짜 어이없습니다."
2. **상황 전개**: 원글 상황을 3~4문장으로 압축. "글쓴이가 ~했다고 합니다" 전문(傳聞)체 유지 — 단정하지 않기.
3. **댓글 반응**: 실제 베댓 1~2개 인용 + 여론 갈림 묘사. "근데 댓글 여론이 심상치 않습니다."
4. **마무리**: 시청자에게 공 넘기기. "여러분이라면 어느 쪽이십니까?"

톤 규칙:
- 과장 수식어 OK: "충격", "난리", "역대급", "레전드"
- 없는 사실 창작 NO. 과장은 형용사까지만, 명사(사건)는 원문 그대로.
- "~인데요", "~습니다" 종결. 문장 짧게. 한 문장 20자 내외.

## 버전 B — 커뮤체 (커뮤니티 재업로드용 글)

커뮤니티 유저가 펌글 소개하는 톤:

- **음슴체 기본**: "~함", "~임", "~라는데", "~각임"
- 제목은 어그로 + 정보: "MBTI로 소개팅 거른 사람 결말.jpg"
- 본문: 상황 요약(음슴체) → 핵심 장면/대사 → "베댓이 레전드임" + 베댓 인용 → 떡밥 질문으로 끝 ("니들 생각은 어떰?")
- ㅋㅋ는 2~4개(ㅋㅋㅋ), 이모티콘 대신 .jpg .txt 같은 확장자 드립 활용
- 반말이지만 조롱 아님 — 독자가 아니라 상황을 향해 웃기

## 공통 금지선 (검수팀이 이 기준으로 자름)

1. 실명/실존 인물·업체 특정 비방 — 익명화해도 특정되면 아웃
2. 성별·지역·세대 집단 혐오 — "vs 구도 소개"는 되고 "한쪽 조롱"은 안 됨
3. 원문 복붙 — 직접 인용은 댓글 1~2줄까지, 본문은 반드시 재구성
4. 출처 누락 — 커뮤니티명 + 원문 링크 항상 표기
5. 없는 전개 창작 — 원문에 없는 결말/반전 붙이지 않기

## 제목 공식 (후보 3개 뽑을 때)

- 결말형: "<상황> 결말.jpg" / "<상황> 근황"
- 의문형: "<A> vs <B> 어느 쪽이 맞음?"
- 수치형: "댓글 <N>개 달린 <주제> 논쟁"
