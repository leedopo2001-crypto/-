# Community Radar — 국내 커뮤니티 데일리 콘텐츠 파이프라인

에펨코리아 · 루리웹 · 디시인사이드 · 네이버 뿜 · 블라인드에서 인기글/vs논쟁글/댓글유발형 글을 매일 발굴해, 캡쳐·다운로드하고, 렉카체·커뮤니티체로 각색한 뒤, 검수를 거쳐 리포트로 보고하는 에이전트 팀 파이프라인.

## 팀 구성

```
팀장 (메인 세션, /daily-community-report 스킬)
 ├─ 발굴팀  community-scout      × 5  (사이트당 1명, 병렬)
 ├─ 선별    크로스 랭킹 (중복 제거 + 상위 N 선정)
 ├─ 수집팀  content-collector    × N  (글당 1명: 스크린샷·본문·댓글·이미지 저장)
 ├─ 각색팀  content-writer       × N  (글당 1명: 렉카체 + 커뮤체 두 버전)
 └─ 검수팀  content-reviewer     × N  (글당 1명: 법적 리스크·사실관계·품질 판정)
```

- 에이전트 정의: `.claude/agents/*.md`
- 파이프라인: `.claude/workflows/daily-community-radar.js` (수집→각색→검수는 글 단위 파이프라인이라 글끼리 서로 기다리지 않음)
- 팀장 프로토콜: `.claude/skills/daily-community-report/SKILL.md`

## 실행 방법

Claude Code 세션에서:

```
/daily-community-report
```

산출물은 `community-radar/output/<YYYY-MM-DD>/`:

```
output/2026-07-06/
├── report.md            # 팀장 최종 보고서
├── raw/<슬러그>/         # 원 소재 (screenshot.png, content.md, comments.md, images/, meta.json)
└── drafts/<슬러그>.md    # 렉카체 + 커뮤체 초안
```

## 데일리 자동화

원격 환경에서 매일 아침 자동 실행하려면 세션에서 트리거 생성을 요청:
"매일 아침 9시(KST)에 /daily-community-report 돌리는 루틴 만들어줘"
(claude-code-remote의 `create_trigger`, cron `0 0 * * *` = UTC 00:00 = KST 09:00, 새 세션 모드)

## ⚠️ 사전 조건: 네트워크 정책

원격 실행 환경의 기본 네트워크 정책은 커뮤니티 도메인 접속을 차단합니다 (2026-07-06 확인: 전 사이트 프록시 403).
환경 설정에서 네트워크 정책을 조정해야 직접 수집이 가능합니다 — [Claude Code on the web 문서](https://code.claude.com/docs/en/claude-code-on-the-web) 참고.
차단 상태에서는 WebSearch 간접 수집만 동작하며 캡쳐/다운로드는 불가합니다.

|---|---|
| 에펨코리아 | 안티봇 강함. 저속 요청 + 차단 시 검색 폴백 |

| 블라인드 | 로그인 필수 — 공개 미리보기/검색 간접 수집만, 수집량 적음 |

## 법적 주의 (검수팀이 강제하는 기준)

- **저작권**: 타인 게시물의 통짜 복붙·무단 재게시는 저작권 침해 소지. 각색본은 반드시 재구성 + 출처 표기. 캡쳐 이미지의 상업적 사용은 별도 판단 필요.
- **명예훼손/모욕**: 실존 인물·업체가 특정되는 콘텐츠는 사실이어도 명예훼손이 성립할 수 있음 (정보통신망법). 검수팀 fail 판정은 뒤집지 않는다.
- **개인정보**: 닉네임·사진 등 식별 정보는 수집 단계부터 마스킹.
- **약관**: 각 커뮤니티 약관상 크롤링 제한이 있을 수 있음. 저속·소량 수집 유지, 차단 우회 금지.
