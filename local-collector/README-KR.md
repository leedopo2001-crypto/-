# 커뮤니티 로컬 수집기

본인 PC에서 돌아가는 수집 프로그램. 더블클릭하면 브라우저 화면이 열리고, 버튼으로 인기글을 불러와 체크해서 수집하거나 주소를 직접 붙여넣어 수집합니다. 결과는 `collected/날짜/글제목/` 폴더에 본문 txt + 이미지 + meta.json으로 저장됩니다.

## 실행 방법 (Windows)

1. 이 `local-collector` 폴더를 통째로 PC에 내려받기
2. **`start.bat` 더블클릭** — 끝. (처음 한 번은 패키지 설치로 1~2분 걸림)
3. 자동으로 열리는 브라우저 화면에서 사용

Python이 없다고 나오면 [python.org](https://python.org)에서 설치하세요. 설치 화면에서 **"Add Python to PATH" 체크 필수**.

| 에펨코리아 | ✅ (cloudscraper) | ✅ | ✅ 포텐 | 셀렉터 검증됨 |
| 루리웹 | ✅ | ✅ | ✅ 유머베스트 | 미검증 |
| 더쿠 | ✅ (XE=에펨과 유사) | ✅ | ✅ 핫게 | 미검증 |
| 네이트판 | ✅ | ✅ | ✅ 랭킹 | 미검증 |
| 보배드림 | ✅ | ✅ | ✅ 베스트 | 미검증 |

| 그 외 사이트 | 자동 추정 | 부분 | — | — |

**"미검증"** 은 사이트 구조를 추정해 코드를 넣었지만 실제 페이지로 확인하지 못했다는 뜻입니다(이 개발 환경에서 접속이 막혀서). 로컬에서 돌려보고 "본문을 찾지 못했습니다"가 뜨면 아래 "안 될 때"를 따라 F12 셀렉터만 알려주세요 — 한 줄 고치면 됩니다.

- **네이버 뿜**: 2020년 서비스 종료 → 제외.
- **블라인드**: 로그인 필수라 로컬 수집기에서 제외 (클라우드 파이프라인에선 검색 기반 간접 수집만).

에펨코리아는 Cloudflare 차단이 있어서 **cloudscraper**로 우회합니다 (requirements에 포함). 그래도 막히면 "Cloudflare 차단" 메시지가 뜨는데, 잠시 후 소량씩 재시도하면 대부분 통과합니다.

## 같이 들어있는 것

| 파일 | 용도 |
|---|---|
| `app.py` + `start.bat` | 브라우저 UI 수집기 (더블클릭 실행) |
| `community_scraper.py` | 명령줄(CLI) 수집기 — `python community_scraper.py <주소>` |
| `ocr_images.py` | 다운받은 이미지 폴더에서 글자 추출 (짤방·표 안 글자) |

CLI/OCR 사용 예:
```
python community_scraper.py https://gall.dcinside.com/board/view/?id=dcbest&no=...
pip install easyocr pillow
python ocr_images.py "글제목_images"
```
OCR은 CPU에서 이미지 한 장당 몇 초 걸립니다(정상). GPU 있으면 `ocr_images.py`에서 `gpu=True`로.

## 진짜 .exe 파일로 만들기 (선택)

Python 설치 없이 아무 PC에서나 실행되는 exe가 필요하면, 본인 PC 명령프롬프트에서:

```
pip install pyinstaller
cd 이_폴더_경로
pyinstaller --onefile --name community-collector app.py
```

`dist\community-collector.exe`가 생깁니다. 실행하면 서버가 켜지니 브라우저에서 `http://127.0.0.1:8747` 접속.

## 안 될 때

- **"본문을 찾지 못했습니다"** → 사이트가 구조를 바꾼 것. 해당 글에서 F12 → 본문 우클릭 → 검사 → 본문을 감싼 `<div class="...">`의 class 이름을 Claude에게 알려주면 한 줄 고쳐드림.
- **에펨코리아 실패가 잦음** → 정상. 안티봇이 세서 IP가 잠시 차단될 수 있으니 천천히, 소량씩.
- **목록 버튼이 실패** → 글 주소를 복사해서 "주소로 직접 수집"에 붙여넣는 방식은 대부분 동작.

## 주의

- 수집물은 개인 보관·소재 정리 용도로. 원문 그대로 재배포는 저작권 문제가 될 수 있습니다.
- 서버에 부담 주지 않게 한 번에 소량씩(수십 건 이하) 수집하세요.
