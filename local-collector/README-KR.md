# 커뮤니티 로컬 수집기

본인 PC에서 돌아가는 수집 프로그램. 더블클릭하면 브라우저 화면이 열리고, 버튼으로 인기글을 불러와 체크해서 수집하거나 주소를 직접 붙여넣어 수집합니다. 결과는 `collected/날짜/글제목/` 폴더에 본문 txt + 이미지 + meta.json으로 저장됩니다.

## 실행 방법 (Windows)

1. 이 `local-collector` 폴더를 통째로 PC에 내려받기
2. **`start.bat` 더블클릭** — 끝. (처음 한 번은 패키지 설치로 1~2분 걸림)
3. 자동으로 열리는 브라우저 화면에서 사용

Python이 없다고 나오면 [python.org](https://python.org)에서 설치하세요. 설치 화면에서 **"Add Python to PATH" 체크 필수**.

## 지원 사이트

| 사이트 | 본문 | 이미지 | 인기글 목록 버튼 |
|---|---|---|---|
| 네이버 블로그 | ✅ (iframe 우회) | ✅ | — |
| 디시인사이드 | ✅ | ✅ | ✅ 실시간베스트 |
| 루리웹 | ✅ | ✅ | ✅ 유머베스트 |
| 에펨코리아 | ✅ (차단 시 실패 표시) | ✅ | ✅ 포텐 |
| 그 외 사이트 | 자동 추정 (안 될 수 있음) | 부분 | — |

블라인드는 로그인 필수 서비스라 지원하지 않습니다.

## 진짜 .exe 파일로 만들기 (선택)

Python 설치 없이 아무 PC에서나 실행되는 exe가 필요하면, 본인 PC 명령프롬프트에서:

```
pip install pyinstaller
cd 이_폴더_경로
pyinstaller --onefile --name community-collector app.py
```

`dist\community-collector.exe`가 생깁니다. 실행하면 서버가 켜지니 브라우저에서 `http://127.0.0.1:8747` 접속.

## 안 될 때

- **"본문을 찾지 못했습니다"** → 사이트가 구조를 바꾼 것. 해당 글에서 F12 → 본문 우클릭 → 검사 → 본문을 감싼 `<div class="...">`의 class 이름을 Claude에게 알려주면 한 줄 고쳐드림.
- **에펨코리아 실패가 잦음** → 정상. 안티봇이 세서 IP가 잠시 차단될 수 있으니 천천히, 소량씩.
- **목록 버튼이 실패** → 글 주소를 복사해서 "주소로 직접 수집"에 붙여넣는 방식은 대부분 동작.

## 주의

- 수집물은 개인 보관·소재 정리 용도로. 원문 그대로 재배포는 저작권 문제가 될 수 있습니다.
- 서버에 부담 주지 않게 한 번에 소량씩(수십 건 이하) 수집하세요.

## 다음 단계 (콘텐츠 제작 파이프라인 연결)

수집한 `collected/` 폴더를 이 리포에 커밋해서 올리면, 클라우드의 각색팀·검수팀 에이전트가 렉카체/커뮤체 초안과 검수 리포트를 만들어줍니다. 자세한 건 `../community-radar/README.md` 참고.
