# 📊 트렌드 데일리 — SNS 트렌드 분석 대시보드

유튜브·구글·인스타그램·릴스·틱톡·X·스레드 등에서 **지금 사람들이 무엇을 검색하고 있는지**,
그리고 **그 주제로 콘텐츠가 얼마나 만들어지고 있는지**를 매일 한 화면에서 확인하는 로컬 웹사이트입니다.

## 실행 방법

Node.js 18 이상만 있으면 됩니다 (별도 패키지 설치 불필요).

```bash
cd sns-trends
node server.js
```

브라우저에서 **http://localhost:3000** 접속.

## 화면 구성

| 패널 | 내용 | 데이터 출처 | API 키 |
|---|---|---|---|
| 🔍 구글 급상승 검색어 | 오늘 가장 많이 검색된 키워드 + 대략적 검색량 + 관련 뉴스 | Google Trends RSS | 불필요 |
| 📈 키워드 콘텐츠 생산량 | 키워드 클릭/검색 시 24시간·7일간 뉴스 기사 수, 유튜브 신규 영상 수, 플랫폼별 검색 바로가기 | Google News RSS, YouTube Data API | 뉴스는 불필요 |
| ▶️ 유튜브 인기 급상승 | 지금 인기 급상승 동영상 순위·조회수 | YouTube Data API v3 | **필요** (무료) |
| 📖 위키피디아 인기 문서 | 어제 가장 많이 조회된 문서 — 대중 관심사 지표 | Wikimedia Pageviews API | 불필요 |

- 상단에서 **국가**(한국/미국/일본/영국/대만)를 전환할 수 있습니다.
- 트렌드 키워드를 클릭하면 해당 주제의 **콘텐츠 생산량**과 유튜브·인스타·릴스·틱톡·X·스레드·네이버 **검색 바로가기**가 표시됩니다.

## 데일리 히스토리

서버가 하루치 데이터를 성공적으로 수집하면 `sns-trends/data/날짜_국가.json` 으로 자동 저장됩니다.
상단 **날짜 선택**에서 저장된 과거 날짜를 골라 그날의 트렌드를 다시 볼 수 있습니다.
매일 한 번 사이트를 열기만 하면 히스토리가 쌓입니다.

## 유튜브 API 키 설정 (선택, 무료)

유튜브 인기 급상승 패널과 키워드별 유튜브 영상 수를 보려면:

1. [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에서
   프로젝트 생성 → **YouTube Data API v3** 활성화 → 사용자 인증 정보에서 **API 키** 발급
2. `sns-trends/.env` 파일 생성:
   ```
   YOUTUBE_API_KEY=발급받은키
   ```
3. 서버 재시작

무료 할당량(일 10,000 유닛)으로 개인 사용에는 충분합니다.

## 인스타그램 / 릴스 / 틱톡 / X / 스레드는 왜 순위가 없나요?

이 플랫폼들은 **공개 트렌드 API를 제공하지 않습니다** (X 트렌드는 유료 API,
틱톡/인스타/스레드는 미제공). 그래서 이 대시보드는:

- 구글 트렌드·위키피디아·유튜브·뉴스로 **"무엇이 뜨는지"** 를 파악하고,
- 각 키워드에 대해 해당 플랫폼의 **검색 결과로 바로 이동하는 링크**를 제공해
  플랫폼별 반응을 직접 확인하는 방식으로 동작합니다.

## 데모 모드

인터넷이 안 되는 환경에서 UI만 확인하려면 **http://localhost:3000/?demo=1** 로 접속하세요.
화면에 "샘플 데이터" 배지가 표시됩니다. (라이브 수집이 전부 실패한 경우에도 자동으로 샘플 데이터가 표시됩니다.)

## 구조

```
sns-trends/
├── server.js          # 의존성 없는 Node 서버 (정적 파일 + 수집 API + 캐시 + 스냅샷)
├── sample-data.json   # 데모/폴백용 샘플 데이터
├── data/              # 데일리 스냅샷 자동 저장 (git 제외)
└── public/
    ├── index.html
    ├── style.css      # 라이트/다크 자동 전환
    └── app.js         # 렌더링 + SVG 차트
```
